# 5.1 Integration touchpoints

&#91;embedded content: Fiscus architecture · one app process, one public path\]

Fiscus is planned as one Bun process built on Apion's stack (NestJS on Fastify, Drizzle, PostgreSQL 18, pg-boss, a React SPA, Nx boundary checks). The phone app is native Flutter (Q-07) and syncs through the private API ([ADR-0002](../architecture/decisions/0002-offline-first-mobile-app.md)); the server and the web app stay TypeScript (Q-01). Only the ingest path is reachable from the internet.

| System | Direction | Mechanism | Trigger | Data exchanged | Source of truth | Failure handling |
| --- | --- | --- | --- | --- | --- | --- |
| Tailscale | Inbound | `tailscale serve` HTTPS to 127.0.0.1 | Every owner, local-client and phone-app request | The web app, all private API traffic and sync | — | Tailnet down: the web app is unreachable by design, and the phone app works from its copy; the ingest path is unaffected |
| Phone app (Flutter) | Both | `sync/push` and `sync/pull` over `tailscale serve`, with the paired token (FR-34) | When the app opens, after each change, and when the connection returns | Mutations up; changed rows and tombstones down | Fiscus database; the phone keeps a copy | Unreachable: works from its copy and keeps its queue (EC-28); 401: asks to be paired again; 410: downloads everything again (EC-23) |
| Caddy (public) | Inbound | Reverse proxy forwarding only `POST /ingest/v1/transactions` | An ingest client call | New transactions, write-only | Fiscus database | Fiscus down: 502; clients retry with the same `Idempotency-Key` |
| PostgreSQL 18 | Both | Localhost connection, pool of 5 | Every request and job | All module data, one schema per module | This database, for all Fiscus data | Down: EC-16 |
| pg-boss | Internal | Job tables in PostgreSQL | Schedules and events | Jobs | PostgreSQL | 3 attempts with exponential backoff, then Failed on the System page |
| Backblaze B2 | Outbound | restic over HTTPS | Nightly at 02:00 server time | Encrypted database dump and data-folder snapshot | The VPS; B2 holds copies | EC-18 |
| SMTP relay | Outbound | SMTP with TLS | Alerts (5.2) | Alert emails | — | Failure logged on the System page and retried the next hour |
| Money Manager | Inbound, once | TSV upload | Migration (US-07) | Historical transactions | Money Manager until the cutover date (Q-03), then Fiscus | Preview errors; rollback within 7 days |
| money-manager-exporter skill | Inbound | Public ingest, or the private API from a tailnet device | A skill run | Transactions from e-receipts | Fiscus | 4xx: the skill shows the error; 5xx or timeout: retry with the same key |
| budgeting skill | Outbound (read) | Private API: budget status and afford check | A skill run on a tailnet device | Budget figures | Fiscus | Unreachable: the skill falls back to a CSV from the full export (US-06) |

Cloud-run Claude sessions may be unable to reach your domain because their own outbound network is allowlisted (A-05). If so, run the skills from a tailnet device, or add a remote MCP connector later (Q-05).
